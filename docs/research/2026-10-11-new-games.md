## Wuthering Waves (Kuro Games)

### Pull history
- **Link:** the PC client writes the Convene record URL to `Client\Saved\Logs\Client.log` (now XOR-obfuscated, keys 0xA5/0xEF) or `KRSDKWebView\debug.log`: `https://aki-gm-resources(-oversea).aki-game.(net|com)/aki/gacha/index.html#/record?...`. Getting it needs a PowerShell script (wuwatracker's `import.ps1`, GPL) — **PC only**, no in-game copy-link like HoYo. Kuro already changed the log once; can break again.
- **API:** `POST https://gmserver-api.aki-game2.net/gacha/record/query` `{playerId, cardPoolId, cardPoolType, serverId, languageCode, recordId}` → records `{cardPoolType, resourceId, qualityLevel, resourceType, name, count, time}`. Reachable (empty probe answered code 0). **No per-pull id**: de-duplication by time + item + count. History window ~6 months (store pulls ourselves). Source: wuwaconvene (PyPI).
- **cardPoolType:** 1 featured resonator, 2 featured weapon, 3 standard resonator, 4 standard weapon, 5 beginner, 6 beginner's choice, 7 other.
- **Export:** no standard (UIGF covers GI/HSR/ZZZ only); wuwatracker has its own JSON (layout not checked).
- **Rules** (official "Convene Details", article 758, 2024 — may be dated): featured resonator 0.8%, hard pity 80, 50/50 then guaranteed, pity carries over; **featured weapon 5★ always the featured one**, pity 80; standard resonator/weapon separate pity, standard weapon lets you pick a target; beginner 5★ within 50; beginner's choice up to 80 with a chosen target. Soft pity ~66–70 (community, unofficial). 160 Astrite per pull.
- **Currencies:** Astrite; Radiant Tide (featured resonator), Forging Tide (featured weapon), Lustrous Tide (standard); Afterglow Coral (4★/5★), Oscillated Coral (3★).

### Live data
- CN app 库街区 (kurobbs.com) has token-protected endpoints (widget with waveplate `gamer/widget/game3/refresh`, sign-in `encourage/signIn/v2`, Tower records `aki/roleBox/akiBox/towerDataDetail`) — reverse-engineered, undocumented, ToS unknown.
- **Global: no official companion API found.** Waveplate, check-in and Tower/Whimpering Wastes records would be "No data yet" outside CN.

## Arknights: Endfield (Gryphline / Hypergryph)

Released worldwide 22 Jan 2026 (PC, PS5, iOS, Android). Versions every 5–7 weeks (update notes: 12 Mar, 17 Apr, 5 Jun, 16 Jul, 2 Sep, "Sanctuary of Ink" Oct 2026). Two server groups: CN (hypergryph.com) and global (gryphline.com).

### Pull history
- **No official export and no file standard** (UIGF covers only hk4e, hkrpg, nap, hk4e_ugc; SRGF is HSR only).
- **In-game history page:** a webview at `ef-webview.{gryphline|hypergryph}.com/page/gacha_…`. On Windows its URL is in `%USERPROFILE%/AppData/LocalLow/Gryphline/Endfield/sdklogs/HGWebview.log` (like Genshin's log trick).
- **API** (behind a `u8_token`, paged by `seqId`): operators `/api/record/char?pool_type=…`, weapons `/api/record/weapon/pool` and `/api/record/weapon`, lifetime counts `/api/record/{type}/rerun-counts`, banner info `/api/content`.
- **Without a PC:** sign in on the web account page (`web-api.gryphline.com/cookie_store/account_token`) and exchange that for a `u8_token`.
- **The server keeps only ~90 days.** Users must import often, or we lose pulls.
- Source for all of this: the community tracker [bhaoo/endfield-gacha](https://github.com/bhaoo/endfield-gacha) (MIT, active, v0.7.0 on 29 Sep 2026). Its only export is Excel.
- Caution: one tracker site (endfieldrecords.com) reportedly spread malware (second-hand report).
- **Pools:** Special (Chartered, limited), Rerun (RE-Factor), Joint, Standard (Basic), Beginner (New Horizons); weapons have special, constant and rerun pools.
- **Rules** ([endfield.wiki.gg Headhunting](https://endfield.wiki.gg/wiki/Headhunting), [Arsenal Exchange](https://endfield.wiki.gg/wiki/Arsenal_Exchange)):
  - 6★ 0.8%, 5★ 8%, a 5★ or better every 10.
  - Hard pity 80, soft pity after 65 (+5% per pull); carries between banners of the same type.
  - Limited: 50/50 with **no guarantee after a loss**. The featured operator is guaranteed at pull 120, once per banner (does not carry). Every 240 pulls gives a duplicate.
  - Free 10-pulls: after 30 pulls (does not count toward pity), and a dossier after 60 pulls for the next banner (counts).
  - Beginner: 40 pulls, guaranteed 6★. Standard: one 6★ selector at 300.
  - Weapons: "issues" of 10 for 1980 Arsenal Tickets; 6★ 4%; a 6★ by the 4th issue (25% featured); featured guaranteed by the 8th, once per banner.
- **Currencies:** Origeometry (paid; 1 = 75 Oroberyl or 25 Arsenal Tickets), Oroberyl (500 per pull), HH Permits (pull vouchers), Arsenal Tickets (also from operator pulls: 2000/200/20 for 6★/5★/4★).

### Live data
- **SKPort** (global, `zonai.skport.com`) and Skland (CN): daily check-in `/web/v1/game/endfield/attendance`; `/api/v1/game/endfield/card/detail` gives stamina (**Sanity**: current, max, time to full), level, world level, pass level, daily activity.
- Sign-in with the `ACCOUNT_TOKEN` cookie from game.skport.com; credentials refresh every 30 min; requests must be signed. Source: [torikushiii/endfield-auto](https://github.com/torikushiii/endfield-auto).
- A CN bot also reads operator panels, the endgame (**Contingency Contract**), the Dijiang base and achievements through Skland. So character import and endgame records are possible.
- Terms: none found about outside tools. Same grey zone as HoYoLAB. The game uses ACE anti-cheat (does not touch web APIs, but worth knowing).

### Differences vs HSR/ZZZ
AIC factory and base building (production chains, power), the Dijiang ship base, region construction. Under OVERRIDE 1 these would be features inside existing modules, not new modules. Weapon gacha paid with tickets from operator pulls. Pity works differently (120 once per banner, free pulls that don't count), so the pity maths and Luck report need per-game rules. Endgame: Contingency Contract. Stamina: Sanity.

- Game data: only wiki.gg; if it slows down there is no fallback.

## Effort estimate (data, pulls and live data; SCHEDULER's view)

Counted in steps like the ones HSR and ZZZ took (one step = one PR with tests).

**Genshin: about 8–10 steps.** Most parts already exist:
- `gacha-import` and the UIGF reader take `hk4e` with a new pool table (two character banners sharing pity, Chronicled + Lightrace sharing pity, Capturing Radiance, Epitomized Path).
- HoYoLAB client: new check-in path (`event/sol`) and Battle Chronicle pages (resin, three endgame modes, Traveler's Diary income).
- `import-nanoka` and `import-schedule`: new game id, official content API app `a1b1f9d3315447cc`, announcement API `hk4e_global`, and a mapping for the "Luna I–VIII" version names (Luna N = 6.(N−1)).
- To check first: the Lightrace pool code.

**Wuthering Waves: about 10–12 steps.**
- Pull import is new code: a PC-only log reader (the log is scrambled; Kuro changed it once already), a new pool table, de-duplication without pull ids, and our own file format.
- Live data: "No data yet" outside CN.
- Data import: nanoka.cc and the official news JSON; new endgame (Tower of Adversity, 2-week periods).

**Endfield: about 12–15 steps, plus decisions.**
- New pull import (link or web sign-in), our own file format, a reminder to import before the 90 days run out.
- New pity rules in the calculator, planner and Luck report.
- SKPort client with request signing.
- Game data from the official news API and the wiki only. No big leak source, so Endfield Intel carries official news and wiki updates only.

All three: `src/games/<name>/` from `games/_template/`, roster pictures, the schedule rhythm (Genshin uses HoYo's 6-week rhythm; Wuthering Waves 42 days with two banner phases; Endfield 5–7 weeks, needs its own offsets), and the research routine extended to the new game.

## Suggested order

1. **Genshin** first if the goal is a full game fast: most pieces exist, and pulls, live data and leaks all work like HSR/ZZZ.
2. **Wuthering Waves** second (or first, if kit checks matter most: LOGIC-CORE's engine fits it best). Accept "No data yet" for live data on global.
3. **Endfield** last. It has the thinnest data (no datamine, no leaks), and its pull history needs the 90-day reminder.

Nothing gets built until everything else is done (owner, via MANAGER).
