## T76 · the app icon is Hagalaz everywhere
- The choice: the owner picked **icon 4, Hagalaz** (the hail rune in the ringed dial) as the
  official app icon on the T64 option sheet (branch `frame/t64-option-sheets`,
  `docs/progress/2026-10-11-frame-t64-options.md` and round 2's "App icon: Hagalaz is the
  official one"). It was never built in: main still used the first icon from T45, the full
  astrolabe ring ("the circle thing").
- Why the old one kept showing: every icon had the same file name as before, and the
  installed app's service worker, the browser and the phone's home screen keep icons by
  name. Now every file has a new name: `public/icons/hagalaz-*` and the manifest is
  `public/hlith.webmanifest`, so no cache can hand back the old picture.
- Where it is used: favicon (SVG + 32 px PNG), iPhone icon (180 px), manifest icons 192 and
  512 plus maskable 192 and 512 (inside the safe zone), the About / Privacy / Terms pages,
  and a new loading mark in `index.html` (the icon on the dark background until the app
  starts; the app replaces it).
- `scripts/app-icons.ts` now draws Hagalaz (same shapes as the sheet). The old icon files
  are kept in `docs/design/app-icon-astrolabe/`.
- If an installed app still shows the old icon: Android updates it on its own within a day
  or so; on iPhone, remove it from the home screen and add it again (iOS never refreshes a
  home-screen icon by itself).
