# docs/progress

One file per finished step, so chats working at the same time never edit the same lines.

- Name: `YYYY-MM-DD-<chat>-<job>.md`, e.g. `2026-10-11-frame-t52b-customise-hub.md`.
- Inside: a bold title line (who, what, branch), then a few plain sentences: what changed,
  where screenshots are, what is left.
- Newest first: `ls -r docs/progress`.
- `docs/PROGRESS.md` keeps "Now", "Next" and the older history.
