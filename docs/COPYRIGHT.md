[LICENSE](../LICENSE)). It is source-available, **not** open source. If you find a copy
(code, design, texts, themes, artwork, badges, rules or data files) hosted or published
somewhere without permission, use the templates below.

Not legal advice. For anything serious, talk to a lawyer.

## Where to report

| Where the copy is | Form |
| --- | --- |
| A GitHub repository | GitHub DMCA takedown form: https://github.com/contact/dmca-notice |
| GitHub's policy (how it works) | https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy |
| A site behind Cloudflare | Cloudflare abuse form: https://abuse.cloudflare.com |
| Any other host | Look up the host with a WHOIS search (for example https://lookup.icann.org) and use its abuse address or form |

Cloudflare often only passes the report to the real host; you may also need to report to
that host directly (Cloudflare's reply names it).

Keep evidence before you report: links, screenshots with dates, and the matching file or
commit in this repository (with its date) showing it was here first.

> host or reuse it has been given.

> source code / the themes in src/... / the texts / the artwork] from my repository without
> permission. Matching originals: [LINKS TO THE ORIGINAL FILES OR COMMITS].
>

## Notes

- A DMCA notice needs a real name and contact details; they may be passed to the other
  person. That is why the blanks are left empty here and never filled in in this repository.
- The licence covers more than code on purpose: copyright in AI-assisted code can be less
  certain, so the design, texts, themes and artwork are named explicitly too.
- Game names, characters and art belong to HoYoverse; we can't file takedowns for those.
