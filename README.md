# PROJECT-HLITH
PROJECT-HLITH (HLIÐSKJÁLF) is a personal command hub for gacha games, named after Odin's high seat from which he sees every world. It plans pulls and odds, reads game data and leaks, builds and scores teams, tracks dailies, events and backlog, and has a built-in assistant. Phone and PC. Every game is a plug-in.

## Develop
- `npm install`, then `npm run dev`.
- `npm run check` before every commit (lint, typecheck, tests, build). `npm run e2e` for the browser test.
- Plan and status: `docs/PLAN.md`, `docs/PROGRESS.md`.
