- FEATURES.md is the feature map from V1. V2 must keep all of it. Read it before designing any module.

- Honest data: never show an unprovable value; use "no data yet".
- Ask questions in chat, not in the question form (the form covers the design).
- Work through the agreed steps without stopping for confirmation; only stop when there is a real question.
